## 🛠️ How to Use ImmerseFree

After launching the application, it runs quietly in the background. Working with it is simple:

1. **On any web page** — Click the ImmerseFree icon in your browser's toolbar to activate bilingual translation. The page will instantly show both the original text and its translation.
2. **On PDFs and EPUBs** — Open your document through ImmerseFree's reader, and you'll get the dual-language view automatically.
3. **On YouTube** — Select a video with subtitles, and ImmerseFree replaces them with dual-language subtitles. For videos without subtitles, use the AI subtitle generator.
4. **On Netflix and Disney+** — Turn on either platform's native subtitles, and ImmerseFree shows both your preferred language and the original side-by-side.

## 🧰 Troubleshooting

### The app won't start
Make sure you extracted the zip file completely before running. If you see an error about missing files, right-click the zip and choose "Extract All" again, then try running the .exe from the extracted folder.

### I can't find the ImmerseFree icon in my browser
After starting the application, it automatically connects to your browser. If you don't see the icon, go to your browser's extensions menu (the puzzle piece icon) and pin ImmerseFree. Restart the application if needed.

### Videos aren't showing subtitles
Ensure the original video has subtitles available (turn on "CC" in the video player). For YouTube videos without subtitles, use the "AI Subtitles" button in the ImmerseFree popup.

### Updates
ImmerseFree updates automatically. If you want to check for a newer version manually, visit the download page again and grab the latest release.
